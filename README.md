# 【Windows専用】ExcelBlankCompressor GUI ｜ Excel/CSV 不要な空行・空列・見えない空白文字一括完全削除機

> **「基幹システムから出力されたExcelに、謎の完全空行や右端の空列が大量に混ざっていてVLOOKUPが動かない…」**  
> **「WebやPDFからコピペしたせいで見えない空白文字（NBSP）がセルに入り込み、関数やピボットテーブルでエラーが出る…」**  
> **「セル内改行（Alt+Enter）のせいで、CSVに出力した瞬間にデータが分裂して行がズレてしまう…」**

『Excel BlankCompressor GUI』は、経理・総務・営業事務・データ分析担当者のために開発された、**不要な空行・空列・見えない空白文字・セル内改行を一網打尽に検知し、数式やテーブルを壊さずに安全に圧縮・クレンジングするWindows専用ポータブルGUIツール**です。

面倒なインストール作業やPython環境の構築は一切不要。解凍してダブルクリックするだけですぐに使えます。

---

## 💡 このツールで解決できるお悩み

- **完全空行・空列の一発パージ**:
  - 表の中間や上下に散らばる「中身のない空行」や、右側に何十列も放置された「空列」を完全自動走査して一括削除。データ領域をキュッとコンパクトに圧縮します。
- **見えない不可視空白（NBSP: `\xa0`）の完全トリミング**:
  - Webサイトや基幹システムからコピーした際に混入する「ノーブレークスペース（NBSP）」や「ゼロ幅スペース」「全角スペース」を漏れなく検知して除去。VLOOKUPやCOUNTIFで一致しないイライラを永久解消します。
- **セル内改行の置換（CSV崩壊・行ズレ事故防止）**:
  - 住所欄や備考欄の中に潜むセル内改行（Alt+Enter）を、「半角スペース」や「読点『、』」に一括置換。CSVエクスポート時に行が分裂して列がズレる致命的な事故を未然に防ぎます（改行の維持も選択可能）。
- **「緑の三角（文字列として保存された数値）」の自動解消**:
  - セルの前後にスペースが付いていたせいで文字列扱いになっていた金額や個数を、自動的に純粋な数値型に戻します。SUM関数や四則演算が正常に動作するようになります。
- **「必須キー列空欄行」の削除オプション**:
  - 「備考欄にメモがあるだけで顧客IDや名前が空っぽのゴミ行」など、指定したキー列が空欄の行を一括で除外できます。
- **複数シートの一括クレンジング**:
  - 1つのExcelブック内に複数のシートがある場合でも、全シートを一括で綺麗にクレンジングして元のシート構成のまま保存します。

## 🛠️ 主な機能・特徴（完全選択式UI）

1. **空行・空列の削除設定**
   - ☑ 完全な空行を一括削除（全セルが空または空白のみの行）
   - ☑ 完全な空列を一括削除（データ右端の空列等）
   - □ 必須キー列が空欄の行も削除する（任意指定）
2. **空白文字・数値のクレンジング設定**
   - ☑ セル前後の不要な空白をトリミング（NBSP・全角スペース・不可視文字）
   - ☑ 数値セルを自動正規化（Excelの「緑の三角」を解消しSUM計算を有効化）
3. **セル内改行の処理モード（4択）**
   - ◎ そのまま維持する（デフォルト）
   - ○ 半角スペースに置換（推奨：CSV崩れ防止）
   - ○ 読点「、」に置換（文章・住所向け）
   - ○ 完全に削除する
4. **安心の非破壊・完全ローカル処理**
   - 元ファイルを直接上書きしません。外部通信ゼロの完全ローカル処理で、機密の社内データも安全に処理できます。

## 🚀 使い方（3ステップで完了）

1. **対象ファイルの選択**
   - 「1. 対象ファイルの選択（Excel / CSV / TSV）」にクレンジングしたいファイルをドラッグ＆ドロップします。
2. **オプションの確認（完全選択式）**
   - 必要に応じて「空行削除」「空白トリム」「改行置換」「必須キー列」などのチェックボックスを選択します（迷った場合はデフォルトのままで安全に最適化されます）。
3. **実行とダウンロード**
   - 「🚀 一括空白削除＆データ圧縮を実行」をクリックします。
   - 削除された行数やトリム箇所のメトリクスを確認し、「📦 クレンジング済みExcel・CSV・レポートを一括ダウンロード (ZIP)」をクリックして保存します。
